# Course request

Triage a training request before design starts. Check the audience, goal, evidence, and obstacles, then draft an action map when learning is part of the response.

## Use it on your own work

Download the packaged skill and read its [instructions](SKILL.md). Give it your audience, setting, goals, and whatever evidence you have. A person confirms the recommended response and the action map. The recommendation may be learning, a change to the work environment, a reference, or a combination.
