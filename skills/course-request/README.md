# Course request

Give course-request your audience, setting, goals, and evidence. It checks what's getting in the way and recommends a response that fits, such as practice, clearer documentation, or a product or workflow change. You confirm the recommendation and, when learning is needed, the action map.

Use it in chat for customer education, internal L&D, or another setting. After the action map, design the experience and approve an outline before using course-dev. That design step isn't packaged here; AI can help propose sequences and practice options while you make the decisions.
