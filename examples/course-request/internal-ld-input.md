## Brief

I work in internal L&D for a facilities-services company. Operations wants a mandatory onboarding course because new service coordinators keep sending routine requests to the wrong team.

Coordinators receive requests from site staff and choose the appropriate service queue. Their work includes using the routing guide, checking that a request contains enough information, and escalating cases they cannot route confidently.

The Operations lead supplied these fictional observations:

- Two newly hired coordinators used an old routing guide still pinned in the team workspace. Both routed the same sample request correctly when given the current guide.
- Another new coordinator could not open the current guide during their first shift. Their access was fixed the next morning.
- A supervisor reported that urgent requests are sometimes assigned without the required details during peak periods. We have not observed that work or established whether new hires do this more often.
- No one has yet checked whether coordinators struggle with genuinely ambiguous routing decisions when the current guide and normal access are available.

There is an existing onboarding module for using the service system. It links to the current guide but does not control what is pinned in the workspace. The guide owner says the current guide is accurate. We have not independently checked the module's practice activities.

The goal is fewer avoidable transfers between service teams. Operations can sample routine requests and check initial routing against the current guide. We have no baseline, agreed target, or timeframe yet.

The team lead can replace workspace links, IT owns access, and Operations owns intake procedures and staffing. I can recommend work but cannot assign it to those teams. Managers already hold weekly check-ins, but we have no evidence that extra coaching is needed and no capacity for a new coaching program. Operations will decide whether to approve the response.
