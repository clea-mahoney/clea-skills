# Internal L&D: example draft output

Authored illustration of a full draft, not a recorded model test or an approved decision. All scenario evidence comes from the fictional companion input. The user requested a complete draft with decisions pending.

## Request

- **Asked for:** a mandatory onboarding course to reduce incorrect routing.
- **Requester and decision-maker:** Operations.
- **Audience and setting:** new internal service coordinators routing requests from site staff.
- **Prompting evidence:** two guide-comparison observations, one resolved access case, and a supervisor's report about peak-period work.

## Goal and performance

- **Operational goal:** fewer avoidable transfers between service teams.
- **Required learner performance:** use the current guide to route routine requests, identify missing details, and escalate uncertain cases.
- **Measure:** sample initial routing accuracy against the current guide. Baseline, target, and timeframe are to confirm. Review transfers separately to distinguish routing errors from later changes in a request.
- **Source and access:** Operations can sample routine requests. Responsibility and sampling criteria still need agreement.
- **Who could check:** Operations, proposed responsibility unconfirmed.

## Diagnosis

| Required action | Obstacle | Evidence or unvalidated assumption | Implication |
|---|---|---|---|
| Use current routing criteria | Obsolete guide is easy to find | Two coordinators routed the sample correctly with the current guide | Replace obsolete links before commissioning training |
| Open the current guide | Missing first-shift access | One supplied case, resolved the next morning | Check provisioning and first-shift readiness |
| Check required details during busy periods | Cause unknown; time pressure is a hypothesis | Supervisor report, not direct observation | Observe the workflow before prescribing an intervention |
| Resolve ambiguous cases | Skill gap not established | No assessment with current guide and working access | Test this before deciding practice is needed |

**Existing coverage:** system onboarding exists and links to the current guide. Practice coverage has not been checked. The guide owner's accuracy statement is supplied evidence, not an independent content review.

## Recommendation

**Decision status:** proposed, awaiting Operations' confirmation.

| Response | Why it fits | Proposed owner and confirmation status | Dependencies or next check |
|---|---|---|---|
| Replace outdated workspace links | Two observed errors disappeared when the current guide was available | Team lead, unconfirmed | Identify and replace the obsolete pinned reference |
| Check guide access before a first shift | One observed obstacle was access | IT and Operations, unconfirmed | Add a practical access check to existing readiness steps |
| Observe peak-period intake and review a small routing sample | The cause and extent of the remaining problem are unknown | Operations with L&D, unconfirmed | Agree on sample, criteria, and observation access |
| Check existing practice before adding learning | A new course may duplicate coverage or miss the cause | L&D, unconfirmed | Review the module, then try a few ambiguous cases with current resources |

A new mandatory course is not supported by the supplied evidence. The smaller response is to correct links and access, then check remaining performance. Extra coaching is also unsupported; the existence of weekly manager check-ins does not establish a coaching need.

**Unvalidated assumptions and checks:** peak-period shortcuts may reflect workflow or workload constraints; observe before diagnosing. Some ambiguous decisions may require practice; test with the current guide before prescribing learning. Two successful sample responses do not establish that all coordinators can handle all routing decisions.

## Handoff

- **Next action:** Operations confirms or changes the recommendation and agrees who will handle the checks.
- **Still awaiting confirmation:** ownership, baseline, target, timeframe, existing practice coverage, and the cause of peak-period problems.
- **Learning decision:** revisit only if the checks reveal a skill or judgment gap. No action map is warranted yet.
